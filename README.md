# Charan Teja Reddy — Portfolio

Interactive portfolio built with **React + Vite**. Fully static — **no backend**.
All content is in [`src/data.js`](src/data.js).

## Run locally

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Create a repo on GitHub, then push this folder to the `main` branch.
2. Repo **Settings → Pages → Source: GitHub Actions**.
3. Every push to `main` builds and publishes the site automatically.

Optional: put your resume at `public/resume.pdf` to enable the Resume button.
